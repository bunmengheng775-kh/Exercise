01 · Hardware

System requirements

Minimum

  • Windows 7 Professional (32-bit or 64-bit) and Windows 10 (32-bit or 64-bit) are supported. Windows 11 is 64-bit only. Windows 7 Home Basic is not supported.
  • 1 GHz CPU, dual-thread or better
  • 512 MB memory
  • 256 MB video memory

Recommended

  • Windows 10 or 11 64-bit. Windows 10 versions 1803 and 1809 provide the best experience.
  • 1.5 GHz CPU, dual-core/four-thread or better
  • 1 GB memory; 512 MB video memory
  • On version 1903 and later, moving windows may not show the blur effect. LTSB may run stably, but crashes can occur more easily.
  • Minimize animations may be unstable on RTX cards; RTX hardware was unavailable for testing.
02 · Display

Graphics driver issues

This issue was observed on hardware that is two years old or older; behavior on newer hardware is unknown. After installing the latest Intel driver from August 15, 2020, on an i7-4720 CPU, DX12 minimize animations stopped working. Another user experienced three or four Dock crashes per day after updating, along with bugs in other software.

After uninstalling the graphics driver and letting Windows 10 Update install its driver, DX12 minimize animations worked again and the Dock stopped crashing. The newest driver is not always the best one; drivers delivered through Windows Update may provide better compatibility and stability. This method is intended for hardware that is two years old or older. It is recommended for integrated graphics; users with discrete graphics or desktop PCs should test it for themselves.

03 · Dependencies

Required runtime components

Refer to the article mentioned in the original guide and download a DirectX repair tool to repair the D3D components and install the VC++ 2015-2019 runtime. MyDock is compiled with VC2019 and requires the VC++ 2015 or later runtime. Windows 7 also needs the update patch mentioned in that article to enable hardware acceleration. Without the patch, the C++ version of MyDock cannot run on Windows 7. The patch cannot be installed on Windows 7 Home editions.

Windows 10 also needs an additional component:

  1. Open Windows Settings and select Apps.
  2. Select Optional features.
  3. Find Graphics Tools. If it is not listed, select Add a feature (+), find Graphics Tools, and install it.
  4. Optionally, open Update & Security, select For developers, then choose Developer mode. Windows will install the required feature.
04 · Common problem

The window does not appear, or MyDock crashes on startup

Cause: the VC2019 runtime is not installed.

Download and extract DirectXRepair4.0:

DirectXRepair4.0 download

Run the appropriate executable in the extracted folder. On Windows 7, run DirectX repair.exe; on Windows 8 or later, run win8_win10.exe. The Update C++ option is selected by default; verify that it is checked. Select Detect and Repair, then restart the computer. If you regularly play demanding AAA games, the repair is usually unnecessary because those games require the same runtime components.

05 · Windows 7

Startup crashes or hardware acceleration does not work

Download Microsoft's Platform Update:

Microsoft Platform Update

Choose the 32-bit or 64-bit package that matches your system. Restart the computer after installation.

If the download is slow, use the copy hosted on Tianyi Cloud:

Tianyi Cloud download

Do not install the program under C:\. If the computer has only one partition, create a MyDock folder under C:\Users\<your-user-name>\AppData\Local and install it there.

06 · Startup

MyDock does not start automatically

The C++ version starts at login through a Windows service. Open Task Manager and check the Services tab for the MyDock service.

If the service is missing, open Dock settings and toggle the startup option off and on again. If it is still missing, add it manually:

  1. Run Command Prompt as administrator.
  2. Enter the command below, replacing the path with your Dock folder. The executable must be MyDock.exe. Keep the space after start= and keep the path in quotation marks.
sc create MyDock displayname= MyDock start= auto binpath= "E:\Program Files (x86)\MyDock\MyDock.exe"

A permissions error means Command Prompt was not opened as administrator.

07 · Animation

Minimize animations do not work

Case 1 · dockmod is not running

In Task Manager, check whether dockmod(64).exe is running and whether minimize animations are enabled in Dock settings. If the process is still missing, open the Dock folder and run dockmod.exe as administrator.

If that does not help, repair the startup task in Task Scheduler. On Windows 10, search for Task Scheduler or press Win+S. Select Task Scheduler Library and look for the mydockmod task. Open it if it exists. Otherwise, select Create Task and configure it as shown in the original guide's screenshots.

Leave the trigger shown in the second screenshot empty: Dock starts dockmod itself, so Windows does not need to trigger it. Set the program path to your dockmod.exe. On 64-bit systems, configure dockmod64.exe in the same way.

Case 2 · dockmod is running

In Dock preferences, set the minimize effect to Scale. If animation works, try other effects such as Genie. If it still fails, try enabling Use GDI screenshot for minimize, disconnecting the second display, or reinstalling the graphics driver used to render Dock's minimize effect. Follow the graphics-driver section above.

On a dual-GPU, dual-monitor setup where the primary display uses integrated graphics and the second display uses the discrete GPU, only the Scale effect may work.

08 · Update

A message appears after updating

Download the update package again from the website's download center and replace the files.

09 · Security

Antivirus reports a detection

If Dock, dockmod32.exe, or dockmod64.exe is detected, add the affected executable to antivirus exclusions. If dockmod.exe exits unexpectedly or minimize animations stop working, Windows Security may have blocked it; add an exclusion in that case as well. The original guide recommends contacting the developer about false positives where possible, since the code triggering detection may be unknown.

Open Windows Security from the Start menu. Select Virus & threat protection, then Manage settings under Virus & threat protection settings. Find Exclusions, select Add or remove exclusions, and add the affected dock(mod).exe. Prefer adding the entire Dock folder.

10 · Weather

The weather icon crashes

Download AMap's weather city-code spreadsheet:

AMap weather city codes

Open the spreadsheet and search for your city. The adcode column contains the weather city code; an adcode is also the first six digits of the corresponding administrative identity code and can be used to look up your city or district.

Open config.ini in the Dock folder and find:

[weather]
citycode=XXXXXX
cityname=XXXXXX

If these lines are missing, add them at the end of config.ini. Replace citycode with the code from the spreadsheet and cityname with your city name. The city name can be any Unicode text.

Important: If your city is not in the spreadsheet, use the code of the nearest listed city. Do not enter a code that is absent from the spreadsheet; doing so may crash the program and prevent it from starting.
